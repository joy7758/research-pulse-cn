# Research Pulse Desktop

Tauri 2 desktop shell for the Research Pulse CN monorepo.

Current scope:
- read-only desktop connection through the existing device-token sync boundary
- Rust-side local SQLite cache
- Today, Papers, Paper Detail, and Settings views

Useful commands:
- `npm install`
- `npm run tauri dev`
- `npm run lint`
- `npm run typecheck`
- `npm run test`
- `npm run build`
