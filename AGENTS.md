# Repository instructions for Codex

This repository is proprietary and confidential.
Do not add any open-source license.
Keep the repository private-ready.

## Product
Build the backend foundation for a commercial China-focused research paper lifecycle system.
Core theme: paper profile, progress tracking, signal snapshots, pulse cards, delivery jobs.

## Current priority
Backend only. No frontend except autogenerated API docs.

## Preferred stack
- Python 3.12
- FastAPI
- SQLAlchemy 2
- Alembic
- Pydantic v2
- PostgreSQL
- Redis
- Pytest
- Ruff
- Docker Compose

## Architecture
Use a modular monolith.
Keep domain and adapters separate.
Do not tightly couple model provider or channel provider.
Provide interfaces for:
- FactCollector
- RuleEngine
- ModelProvider
- CardValidator
- ChannelAdapter

## Delivery channels
Implement now:
- Console adapter
- DingTalk webhook adapter skeleton
- WeChat adapter interface skeleton

## Guardrails
- No secrets in repo
- Add .env.example, never commit .env
- Prefer simple, readable code
- Add tests for core flows
- Add docs for local development
- Use UTC in persistence
- Keep files and names production-friendly
