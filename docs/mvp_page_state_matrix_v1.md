# MVP Page State Matrix v1

## 目标

本文件定义每个 MVP 页面在不同状态下应该向用户呈现什么、允许做什么、不允许误导什么。

状态矩阵的目的是避免后续前端实现时：

- 把 warning 做成 error
- 把 preview 误写成已发送
- 把空状态做成空白页

## 状态定义

| 状态 | 含义 |
| --- | --- |
| `default` | 默认可交互状态 |
| `empty` | 当前无数据，但不是错误 |
| `loading` | 正在等待生成或读取结果 |
| `success` | 当前步骤已完成，可继续下游动作 |
| `warning` | 可继续，但有建议处理的问题 |
| `error` | 当前无法继续，需要修正或返回 |
| `draft` | 结果是草稿，不代表已发送 |
| `preview` | 结果是预览，不代表已发布 |
| `not_sent` | 尚未真实发送或推送 |
| `disabled` | 当前操作暂不可用 |
| `offline` | 不依赖网络也可工作的本地或后端内生流程 |

## 共通误导文案禁区

所有页面都禁止出现以下误导表达，除非未来真的实现对应能力并有可信回执：

- 已发送成功
- 已推送成功
- 已登录微信
- 已完成支付
- 已发布到小程序
- 已调用系统通知
- 已同步外部模型结果
