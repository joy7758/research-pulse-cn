# MVP Accessibility Readability v1

## 目标

本文件定义 MVP 的可访问性与中文可读性规则。

目标不是覆盖完整无障碍规范，而是确保后续实现不会因为视觉收敛而牺牲：

- 可读性
- 可操作性
- 可恢复性

## 总原则

### 1. 文字优先于装饰

科研工作台的核心是阅读和判断，因此文字信息必须优先。

### 2. 不用颜色作为唯一表达方式

所有状态都必须同时依赖：

- 文字
- 位置
- 层级

而不是只依赖颜色。

### 3. 用户可恢复

warning 和 error 都必须能让用户知道下一步怎么做。

## 键盘可达

- 主动作必须能通过键盘快速聚焦
- drawer 打开后焦点应进入 drawer
- drawer 关闭后焦点应回到原触发元素附近
- 复制按钮、保存按钮、关闭按钮必须可聚焦

## 焦点状态

- 焦点必须清晰可见
- 焦点样式不能只靠颜色微差
- 焦点不应被卡片阴影或背景吃掉

## 对比度原则

- `text.primary` 与背景保持高对比
- `text.secondary` 虽弱化，但必须可读
- warning、error、draft、preview 文字必须具备足够对比

## Loading 不阻塞理解

- loading 状态应说明正在做什么
- 骨架屏或占位必须帮助用户理解页面结构
- 不要只出现“转圈 + 无说明”

## Error 可恢复

- error 必须带重试、返回或查看问题记录之类的下一步
- 不允许出现只有“失败了”的死路状态

## Warning 有建议

- warning 必须包含：
  - 是否可继续
  - 建议处理什么

例如：

- 这条记录缺少年份，仍可导入，建议后续补全

## EmptyState 有下一步动作

- 空状态不是终点
- 空状态必须配套一个下一步动作

例如：

- 先导入论文
- 先生成今日 Pulse
- 从重点论文中补充下一步动作

## 中文按钮长度

- 中文按钮文案应尽量短
- 推荐 4 到 10 个汉字左右
- 超过时应谨慎判断是否可以改成更直接的动词短语

## 长标题截断与展开

- 论文标题优先换行，不优先省略
- 如果卡片高度需要控制，可折中到 2 到 3 行
- 详情区和 drawer 应允许完整展开

## 作者 / 年份 / 来源可读性

- 作者、年份、来源是论文判断的关键辅助信息
- 它们必须是次级信息，但不能因为弱化而难读

## Payload preview 可复制

- payload 预览应支持清晰复制路径
- 复制反馈应明确
- 不应要求用户手动框选长段 JSON

## `draft / preview / not_sent` 文字说明

以下状态必须有文字说明，不可只用颜色：

- 草稿
- 预览
- 未发送

尤其在：

- 公众号摘要草稿页
- 桌面通知草稿页
- 小程序详情预览页

## 非技术用户适配

本 MVP 需要照顾：

- 导师
- 编辑
- 科研助理

这些用户不应被要求理解：

- payload
- schema
- parser
- raw source payload
- share-safe 的内部实现方式

## 中文阅读体验规则

- 段落不宜过长
- 句子优先短句
- 动词优先明确
- 说明文字要可扫读

## Accessibility / Readability 验收标准

1. 焦点可见。
2. 主动作可用键盘触达。
3. warning / error / draft / preview 都有文字说明。
4. 中文按钮与标题不会因过长而难读。
5. 长标题在详情层可以完整阅读。
6. 非技术用户不需要理解底层术语也能继续。
