# MVP Wireframes v1

## 目标

本文件把 Design-1 的界面原则转成可执行的 MVP 线框规格。

本阶段只定义：

- 页面结构
- 区块层级
- 主动作与次动作
- 明确禁止项

本阶段不定义：

- 高保真视觉
- 前端实现
- 真实平台接入

## 总体布局原则

### 1. 桌面端优先

MVP 先以桌面浏览器宽屏工作台为主要布局参考。

原因：

- 研究生、博士生、导师的主工作场景仍是电脑
- 论文进度与 Pulse 处理天然适合宽屏阅读
- 小程序与桌面通知在本阶段仍是 preview / draft

### 2. 默认三层结构

```text
+--------------------------------------------------------------+
| TopStatusBar                                                 |
+-----------+----------------------------------+---------------+
| LeftNav   | MainContent                      | RightDrawer   |
|           |                                  | (optional)    |
|           |                                  |               |
+-----------+----------------------------------+---------------+
```

说明：

- `LeftNav`：只放一级导航和少量上下文
- `MainContent`：始终承载当前页面主任务
- `RightDrawer`：按需打开，不默认占满主流程

### 3. 每页一个主动作

每个页面只允许一个视觉上最强的主按钮。

次动作可以存在，但不能和主动作争抢注意力。

### 4. 首页不是“论文总库”

首页必须优先回答：

1. 今天该看什么
2. 哪些论文要处理
3. 下一步做什么

### 5. 草稿与预览要显式标识

以下页面必须把状态放在首屏：

- 公众号摘要草稿页
- 桌面通知草稿页
- 小程序详情预览页

## 全局框架

### LeftNav

建议内容：

- 今日 Pulse
- 导入
- 论文进度
- 渠道草稿
- 设置

二级分组建议：

- 渠道草稿
  - 公众号摘要草稿
  - 桌面通知草稿
  - 小程序详情预览

### TopStatusBar

建议内容：

- 当前日期
- 当前页面标题
- 最近生成时间
- 状态提示：`草稿` / `预览` / `未发送`

不建议放：

- 大量全局配置
- 复杂筛选器
- 多个同级 CTA

### RightDrawer

适合承载：

- 论文详情
- 问题记录详情
- payload preview
- share-safe 说明

不适合承载：

- 整页主流程
- 多步向导主操作

## 页面线框

## A. 首页：今日 Research Pulse

### 页面目标

让用户一进系统就知道今天该做什么。

### ASCII wireframe

```text
+--------------------------------------------------------------------------------------+
| 今日科研 Pulse | 2026-04-19 | 最近生成：09:20                     [刷新今日 Pulse]  |
+----------------------+------------------------+--------------------------------------+
| 今日概览             | 今日重点论文           | 下一步动作                           |
| - 高优先级：2        | [论文卡片 1]           | [动作卡片 1]                         |
| - 待补全：1          | [论文卡片 2]           | [动作卡片 2]                         |
| - 待筛选：3          |                        |                                      |
+----------------------+------------------------+--------------------------------------+
| 继续阅读与分析                                                              |
| [论文卡片 3]  [论文卡片 4]  [论文卡片 5]                                    |
+--------------------------------------------------------------------------------------+
| 元数据待补全                                                                  |
| [问题论文卡片 1] [问题论文卡片 2]                                            |
+--------------------------------------------------------------------------------------+
| 新导入待筛选                                                                  |
| [待筛选论文卡片 1] [待筛选论文卡片 2]                                        |
+--------------------------------------------------------------------------------------+
| 快速操作                                                                       |
| [导入论文] [生成公众号草稿] [生成桌面通知草稿] [小程序详情预览]               |
+--------------------------------------------------------------------------------------+
| 输入一句话：帮我整理今天该看的论文                                            |
+--------------------------------------------------------------------------------------+
```

### 主动作

- `刷新今日 Pulse`

### 次动作

- `导入论文`
- `生成公众号草稿`
- `生成桌面通知草稿`
- `小程序详情预览`

### 不要出现什么

- 全量论文表格
- 高级导入设置
- collection / tag 树状管理中心

## B. 导入页

### 页面目标

把导入压缩成“拖入或粘贴 -> 自动识别 -> 进入预览”。

### ASCII wireframe

```text
+--------------------------------------------------------------------------------------+
| 导入论文                                                                         |
+--------------------------------------------------------------------------------------+
| [拖拽区：拖入 PDF / CSV / BibTeX / RIS / CSL JSON]                                |
|                                                                                    |
| 或                                                                                |
|                                                                                    |
| [粘贴区：粘贴引文内容]                                                             |
+------------------------------------------+-------------------------------------------+
| 最近导入记录                             | 支持格式                                 |
| - 今天 09:00 CSV                         | - CSL JSON                               |
| - 昨天 21:30 RIS                         | - BibTeX                                 |
| - 昨天 20:10 PDF folder                  | - RIS                                    |
|                                          | - CSV / TSV                              |
|                                          | - PDF 文件夹占位导入                     |
+------------------------------------------+-------------------------------------------+
| [开始识别]                                 [查看支持格式]                           |
+--------------------------------------------------------------------------------------+
```

### 主动作

- `开始识别`

### 次动作

- `查看支持格式`

### 不要出现什么

- 先让用户手动选择复杂格式
- 高级字段映射表
- 批量规则配置器

## C. 导入预览页

### 页面目标

让用户直接看到“哪些能导、哪些有问题、接下来怎么做”。

### ASCII wireframe

```text
+--------------------------------------------------------------------------------------+
| 导入预览                                                                         |
+---------------------+---------------------+---------------------+--------------------+
| 可导入 9            | 有 warning 2        | 不可导入 1          | 重复提示 1         |
+--------------------------------------------------------------------------------------+
| 记录预览列表                                                                       |
| [#1] 论文标题 A | 可导入 | warning: 缺年份                                           |
| [#2] 论文标题 B | 可导入 | 无                                                       |
| [#3] 无题名      | 不可导入 | error: 缺少题名                                         |
+--------------------------------------------+-----------------------------------------+
| 字段预览                                   | 问题记录列表                            |
| title: ...                                  | - #1 缺少年份                           |
| authors: ...                                | - #3 缺少题名                           |
| year: ...                                   | - #5 DOI 可能重复                       |
+--------------------------------------------+-----------------------------------------+
| [确认导入可导入记录]                        [只看问题记录] [返回修改]               |
+--------------------------------------------------------------------------------------+
```

### 主动作

- `确认导入可导入记录`

### 次动作

- `只看问题记录`
- `返回修改`

### 不要出现什么

- 技术错误栈
- raw payload 大段暴露
- 用户必须手工理解 schema 差异

## D. 导入完成页

### 页面目标

导入后立刻把用户带回研究推进，而不是停留在“导入成功”提示。

### ASCII wireframe

```text
+--------------------------------------------------------------------------------------+
| 导入完成                                                                         |
+----------------------+----------------------+----------------------+-------------------+
| 已导入 9             | 跳过 2               | 失败 1               | 下一步建议         |
+--------------------------------------------------------------------------------------+
| 建议你现在继续做这些事：                                                           |
| - 查看今日 Pulse，确认今天的重点论文                                               |
| - 处理 2 条元数据待补全记录                                                        |
| - 把新导入论文中的 3 篇标记为待读或精读中                                          |
+--------------------------------------------------------------------------------------+
| [查看今日 Pulse]                            [查看论文进度] [继续导入]               |
+--------------------------------------------------------------------------------------+
```

### 主动作

- `查看今日 Pulse`

### 次动作

- `查看论文进度`
- `继续导入`

### 不要出现什么

- 复杂日志页
- 导入实现细节说明
- 一堆技术字段确认框

## E. 论文进度页

### 页面目标

用“研究推进”视角看论文，而不是用数据库管理视角看论文。

### ASCII wireframe

```text
+--------------------------------------------------------------------------------------+
| 论文进度                                                                       |
+------------------+---------------------------------------------------+--------------+
| 筛选             | 进度统计                                          | 主动作       |
| - 全部           | - 待读 12                                         | [更新选中进度]|
| - 待读           | - 精读中 5                                        |              |
| - 略读中         | - 待补全 2                                        |              |
| - 精读中         | - 高优先级 3                                      |              |
| - 已读           |                                                   |              |
| - 待补全         |                                                   |              |
| - 有下一步动作   |                                                   |              |
| - 高优先级       |                                                   |              |
+------------------+---------------------------------------------------+--------------+
| 论文卡片列表                                                                       |
| [论文卡片 A] 标题 / 作者 / 来源 / 状态 / 优先级 / 下一步动作                        |
| [论文卡片 B] 标题 / 作者 / 来源 / 状态 / 优先级 / 元数据提醒                        |
| [论文卡片 C] 标题 / 作者 / 来源 / 状态 / 优先级 / 下一步动作                        |
+--------------------------------------------------------------------------------------+
| [导入论文] [生成 Pulse]                                                           |
+--------------------------------------------------------------------------------------+
```

### 主动作

- `更新选中进度`

### 次动作

- `导入论文`
- `生成 Pulse`

### 不要出现什么

- 叫做“论文管理后台”
- 默认巨型表格和几十个列
- 用户必须先学会筛选语言才能用

## F. 论文详情侧栏 / Drawer

### 页面目标

点击论文后直接在当前工作流内完成查看和更新，不打断上下文。

### ASCII wireframe

```text
+------------------------------------------+
| 论文详情                                  |
+------------------------------------------+
| 标题                                      |
| 作者 / 年份 / 来源                        |
| DOI / URL                                 |
+------------------------------------------+
| 阅读状态： [待读 v]                       |
| 研究阶段： [relevant v]                   |
| 优先级：   [high v]                       |
+------------------------------------------+
| 下一步动作                                |
| [整理方法部分，周五前发给导师           ] |
+------------------------------------------+
| 笔记                                      |
| [用户笔记输入区                         ] |
+------------------------------------------+
| 元数据提醒                                |
| - 缺少年份                                |
| - DOI 可能重复                            |
+------------------------------------------+
| [保存进度]                                |
| [加入今日 Pulse] [标记已读] [关闭]        |
+------------------------------------------+
```

### 主动作

- `保存进度`

### 次动作

- `加入今日 Pulse`
- `标记已读`
- `关闭`

### 不要出现什么

- 跳走到全新页面才允许编辑
- 技术字段命名直接暴露给用户
- 复杂多标签编辑器

## G. Research Pulse 详情页

### 页面目标

把首页摘要扩展成可浏览、可继续转换为多端草稿的详细结构。

### ASCII wireframe

```text
+--------------------------------------------------------------------------------------+
| 今日 Research Pulse | 已生成 09:20                                                 |
+--------------------------------------------------------------------------------------+
| 今日重点论文                                                                       |
| [PulseSection / PaperCard 列表]                                                     |
+--------------------------------------------------------------------------------------+
| 继续阅读与分析                                                                     |
| [PulseSection / PaperCard 列表]                                                     |
+--------------------------------------------------------------------------------------+
| 下一步动作                                                                         |
| [NextActionCard 列表]                                                               |
+--------------------------------------------------------------------------------------+
| 元数据待补全                                                                       |
| [MetadataWarningCard 列表]                                                          |
+--------------------------------------------------------------------------------------+
| 新导入待筛选                                                                       |
| [TriageCard 列表]                                                                   |
+--------------------------------------------------------------------------------------+
| [生成公众号摘要草稿] [生成桌面通知草稿] [小程序详情预览]                            |
+--------------------------------------------------------------------------------------+
```

### 主动作

- `生成公众号摘要草稿`

### 次动作

- `生成桌面通知草稿`
- `小程序详情预览`

### 不要出现什么

- 伪造论文摘要
- 显示成已发布内容
- 复杂内容编辑器

## H. 公众号摘要草稿页

### 页面目标

只让用户处理“草稿内容”，不让用户误解为已发送。

### ASCII wireframe

```text
+--------------------------------------------------------------------------------------+
| 微信公众号每日摘要草稿                         状态：draft / not_sent                |
+--------------------------------------------------------------------------------------+
| 标题：今日科研 Pulse：3 个待处理事项                                                |
| 摘要：今日建议优先处理 2 篇高优先级论文，其中 1 篇已有下一步动作。                  |
+-------------------------------------------+-----------------------------------------+
| Markdown 预览                             | Plain Text 预览                         |
| ## 今日重点论文 ...                       | 今日重点论文 ...                        |
| ## 下一步动作 ...                         | 下一步动作 ...                          |
+-------------------------------------------+-----------------------------------------+
| [复制 Markdown]                            [复制纯文本] [返回 Pulse]                |
+--------------------------------------------------------------------------------------+
```

### 主动作

- `复制 Markdown`

### 次动作

- `复制纯文本`
- `返回 Pulse`

### 不要出现什么

- `发送`
- `群发`
- `素材上传`
- `获取 access_token`
- `发送成功`

## I. 桌面通知草稿页

### 页面目标

把 Pulse 转成短文本提醒，不假装成真实推送。

### ASCII wireframe

```text
+--------------------------------------------------------------------------------------+
| 桌面通知草稿                                   状态：draft / not_sent               |
+--------------------------------------------------------------------------------------+
| notification title: 今日科研 Pulse：3 个待处理事项                                  |
| notification body : 有 2 篇高优先级论文、1 个下一步动作、1 条元数据待补全。         |
+------------------------+-----------------------+-------------------------------------+
| badge count: 3         | urgency: high         | deep link: research-pulse://...     |
+--------------------------------------------------------------------------------------+
| actions                                                                              |
| - 查看今日 Pulse                                                                     |
| - 查看下一步动作                                                                     |
| - 补全元数据                                                                         |
+--------------------------------------------------------------------------------------+
| payload preview                                                                      |
| { title, body, badge_count, urgency, deep_link, actions, ... }                      |
+--------------------------------------------------------------------------------------+
| [复制 payload]                              [返回 Pulse]                            |
+--------------------------------------------------------------------------------------+
```

### 主动作

- `复制 payload`

### 次动作

- `返回 Pulse`

### 不要出现什么

- `立即推送`
- `调用系统通知`
- `已推送成功`

## J. 小程序详情预览页

### 页面目标

输出未来小程序详情页需要的数据与路径预览，但不伪装成真实小程序。

### ASCII wireframe

```text
+--------------------------------------------------------------------------------------+
| 小程序详情预览                                状态：preview / share-safe            |
+--------------------------------------------------------------------------------------+
| tabs: [今日 Pulse] [单篇论文] [下一步动作] [元数据待补全] [新导入待筛选]            |
+--------------------------------------------------------------------------------------+
| title / subtitle / summary                                                           |
+--------------------------------------------+-----------------------------------------+
| cards                                      | share card                              |
| [Card 1]                                   | title                                   |
| [Card 2]                                   | summary                                 |
| [Card 3]                                   | path                                    |
+--------------------------------------------+-----------------------------------------+
| navigation path: /pages/pulse/detail?...                                             |
| visibility notes: 当前结果仅用于 preview，已按 share-safe 规则裁剪                  |
+--------------------------------------------------------------------------------------+
| [复制小程序 detail payload]                 [复制 path] [复制 share card]            |
+--------------------------------------------------------------------------------------+
```

### 主动作

- `复制小程序 detail payload`

### 次动作

- `复制 path`
- `复制 share card`

### 不要出现什么

- `微信登录`
- `支付`
- `订阅消息`
- `小程序码`
- `真实发布`

## K. 设置页

### 页面目标

只放 MVP 运行需要的最小偏好，不做复杂运营后台。

### ASCII wireframe

```text
+--------------------------------------------------------------------------------------+
| 设置                                                                               |
+--------------------------------------------------------------------------------------+
| 默认时区                      [Asia/Shanghai v]                                     |
| 每个 section 最大条数         [5]                                                   |
| 包含低优先级                  [开关]                                                |
| 包含已归档                    [开关]                                                |
| 草稿免责声明开关              [开关]                                                |
+--------------------------------------------------------------------------------------+
| [保存设置]                                                                          |
+--------------------------------------------------------------------------------------+
```

### 主动作

- `保存设置`

### 次动作

- 无，或仅保留返回

### 不要出现什么

- access token 管理
- 渠道认证中心
- 支付配置
- 复杂权限面板

## 页面共通禁区

以下内容在所有 MVP 线框中都不应默认出现：

- 真实发送成功
- 真实推送成功
- 微信登录成功
- 小程序支付成功
- 原生系统通知开关
- 外部模型调用状态
- CNKI / Wanfang / VIP 正式导入配置器
- Zotero plugin / connector / sync 配置器

## 线框交付说明

Design-2 交付的是：

- 页面结构
- 区块层级
- ASCII wireframe
- 主动作与次动作
- 禁止项

它不是视觉设计稿，也不是前端实现说明。
