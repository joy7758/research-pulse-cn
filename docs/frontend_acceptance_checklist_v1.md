# Frontend Acceptance Checklist v1

## Frontend-1 验收清单

- [ ] 首页第一屏就是今日 Research Pulse。
- [ ] 首版页面少于或等于 3 个核心页面。
- [ ] 每页只有一个主动作。
- [ ] 页面使用中文。
- [ ] 不暴露技术字段。
- [ ] warning / error 都转成用户可理解建议。
- [ ] `draft / preview / not_sent` 显示明确。
- [ ] 可以使用 demo JSON 离线运行。
- [ ] mock mode 和 real API mode 的边界清楚。
- [ ] 不接真实微信。
- [ ] 不接真实小程序。
- [ ] 不接真实桌面通知。
- [ ] 不接外部 LLM。
- [ ] 不接外部网络。
- [ ] 不新增 admin 后台。
- [ ] 不破坏 API contract。
- [ ] 不破坏 schema contract。
- [ ] 不新增 migration。
- [ ] 不新增 backend 功能。
- [ ] 不先做复杂登录和权限。

## 页面级验收

### 首页

- [ ] 首屏回答今天该看什么。
- [ ] 首屏回答哪些论文要处理。
- [ ] 首屏回答下一步做什么。

### 导入 / 导入预览

- [ ] 不要求用户先理解格式。
- [ ] 预览页先展示结果，再展示问题。
- [ ] 问题记录可单独查看。

### Pulse 详情

- [ ] sections 清楚。
- [ ] 草稿状态不误导为已发送。
- [ ] 后续渠道按钮不制造真实平台接入错觉。

## 范围级验收

- [ ] 不做登录。
- [ ] 不做组织 / 团队。
- [ ] 不做完整文献库。
- [ ] 不做高级筛选。
- [ ] 不做设置中心。
- [ ] 不做 admin 轨道。
