- Do not add new delivery channels.

Primary goal:
Strengthen the already-added read-only result share registry inside apps/group-workspace-admin-web.

This phase should make the registry more usable for operators:
1. stronger filtering
2. stable sorting
3. filter summary / chips
4. grant <-> alias relationship shortcuts
5. quick open drilldown from registry rows
6. still strictly read-only

For aliases:
- resultShareGrantId nullable

Sort model:
- ResultShareRegistrySortInput

Minimum sort fields:
- createdAt desc/asc
- lastUsedAt desc/asc
- expiresAt desc/asc
- shareKind asc/desc
- status asc/desc

Requirements:
- build query params deterministically

- do not add backend sort unless it is a tiny read-only compatibility fix
- no mutation endpoints

- tie-breaker:

- document helper behavior in tests
